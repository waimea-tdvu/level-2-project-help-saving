# Project Requirements

## Identified Problem or Need

Many people struggle to manage their spending or save money consistently because they do not keep track of their daily expenses. Without a clear record of where their money goes, it is difficult to saving money for them. They need reminders and feedbacks when they are spending too much so they can adjust their spending before the end of the week. My project will solve this problem.

## End-User Requirements

My main end-users is for my mom and my sister. They want a simple and easy to use application that allows them to record their daily expenses quickly, and set a savings target. They can track their current spending and savings progress. And receive a weekly summary showing their spending and their savings goal that they achieved.


## Proposed Solution

The proposed solution is a mobile expense and savings tracker application. Users can record their daily expenses, set a weekly savings target. and monitor their progress throughout the week. At end of each week, the application will generate a summary of total spendings and savings. If the user's savings are close to or below their weekly savings target, it will display a warning notification on their phone and the smile face will go down to sad face to notice them adjust their spending.


# Relevant Implications

## Usability

Usability refers to how easy and efficient the system is for users to learn and use.

### Relevance to the System

This app is intended for everyday use, so the users should be able to add expenses, set savings target, and view report quickly without confusion

### Impact / Considerations

The interface should be simple, with clear navigation, readable text, and easy-to-use button. Recording expense should be take a few seconds



## Privacy

Privacy is to protecting user personal and financial information from unauthorized access

### Relevance to the System

This app will stores personal financial data, including spending records and savings goals, which should remain private.

### Impact / Considerations

The system should securely store user data, require user authentication if accounts are used, and avoid sharing financial information with other users.



## Functionality

Functionality is refers to the features the system provides to meet user needs.

### Relevance to the System

The project's main purpose is to help users track expenses and reach their savings target.

### Impact / Considerations

This application should includes adding users daily expenses, displaying spendings and savings progress, set weekly target, sending warning notification to the users when their savings is below or near to the savings target, and generating a summary of each week at the end of the week.



## Ethical

Ethics includes developing technology responsibly and respecting users' rights and wellbeing.

### Relevance to the System

The application encourages better financial habits, but it should not pressure or shame users if they do not reach their savings goals.

### Impact / Considerations

The warning notifications should be supportive and encouraging users. This app should be transparent about how it stores and uses user data and avoid misleading users with inaccurate financial information.



## Legal

Legal refers to the laws and regulations that must be followed when developing and using a software system.

### Relevance to the System

The expense and savings tracker collects and stores users' personal and financial information. The system must comply with privacy and data protection laws to ensure users' information is handled responsibly. If the application uses third-party images, icons, or code, I must also respect copyright and software licensing requirements.

### Impact / Considerations

This application should protect users' personal data, clearly explain how information is collected and used, and only use content that is licensed or created by the developer. I need to ensure that any open-source software or libraries are used according to their licences.
